# AutoLoc API

API REST de gestion de location de véhicules — Projet **UP ASI** (Architecture des Systèmes d'Information).

## 📋 Description

Application Spring Boot permettant la gestion complète d'un service de location de véhicules :
- Gestion des véhicules (voitures, SUV, utilitaires)
- Gestion des agences, clients et employés
- Réservations, contrats et paiements
- Maintenance et équipements
